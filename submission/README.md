# Submission documents

Place the four required documents here. Replace `0x404` with the registered team name.

| File | Document |
| ---- | -------- |
| `SDC2026_0x404_Preliminary.pdf` | Preliminary submission |
| `SDC2026_0x404_TechDeclaration.pdf` | Technology declaration |
| `SDC2026_0x404_Replit_POU.pdf` | Replit proof of use |
| `SDC2026_0x404_Runpod_POU.pdf` | RunPod proof of use |

The templates for these documents are in the organisers' Google Drive folder linked from the
[submission template](https://github.com/michaelzhngg/SDC_Hackathon_Submission_Template).
